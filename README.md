# Codex

[Codex](https://developers.openai.com/codex) by OpenAI as an AI provider for Consulo.

Chats run through the native Codex command line (`codex app-server`), one long-lived process per account speaking its
JSON-RPC protocol over standard input and output - no Node.js is needed. The threads Codex keeps for the project show
in the chat tree, the titles Codex generates name the chats, and approvals of commands and file changes, and the
questions of the model, are answered in the AI Chat tool window. Sign in with ChatGPT or an OpenAI API key.
